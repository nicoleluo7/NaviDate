# Navidate

The application is in [`navidate/`](navidate/README.md).

```bash
cd navidate
nvm use
npm ci
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000. Node 24 is required. The local planner needs no credentials.

See the application README for provider setup, tests, data verification, architecture, the three-person work split and hackathon demo script. Nothing has been deployed or pushed remotely.
